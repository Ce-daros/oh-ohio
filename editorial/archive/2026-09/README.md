# Archived editorial artifacts (2026-09)

These files lived outside the repository, in the project's parent directory,
while the site was being built. They are archived here unchanged so the
repository holds its full editorial record.

- `explore-expansion.json`, `make-culture-expansion.json`, `live-expansion.json`:
  planned content expansions. Every slug in these files has since been realized
  as a document under `src/content/documents/` (verified 2026-09-26).
- `journal-features-research.md`, `journal-guides-research.md`: research notes
  behind the expansions.
- `copy-review-journal.md`, `editorial-copy-review-existing.md`,
  `final-site-review.md`: copy reviews of the drafts that became the current
  documents.
- `journal-art-manifest.json`: art assignment records for journal covers.

Nothing in the site imports from this directory. The active editorial guides
live in `site/editorial/`.
